# AD203 — Weekly PDFs

Drop one PDF into each `week-XX` folder and name it exactly as listed below.
The site looks for these filenames; no code changes are needed once the file exists.

| Week | Folder | Required filename | Topic |
|------|--------|-------------------|-------|
| 1 | `week-01` | `week-01.pdf` | Introduction to Artificial Intelligence |
| 2 | `week-02` | `week-02.pdf` | Agents & Problem Formulation |
| 3 | `week-03` | `week-03.pdf` | Uninformed Search |
| 4 | `week-04` | `week-04.pdf` | Informed Search |
| 5 | `week-05` | `week-05.pdf` | Local Search |
| 6 | `week-06` | `week-06.pdf` | Adversarial Search |
| 7 | `week-07` | `week-07.pdf` | Constraint Satisfaction |
| 8 | `week-08` | `week-08.pdf` | Probability |
| 9 | `week-09` | `week-09.pdf` | Bayesian Networks |
| 10 | `week-10` | `week-10.pdf` | Decision Theory |
| 11 | `week-11` | `week-11.pdf` | Markov Decision Processes |
| 12 | `week-12` | `week-12.pdf` | Reinforcement Learning |
| 13 | `week-13` | `week-13.pdf` | Deep Learning & Deep RL |
| 14 | `week-14` | `week-14.pdf` | LLMs, Ethics & Revision |

To add more than one PDF for a week, add another entry to `js/data.js` following
the same pattern and put the file in the matching `week-XX` folder.
